# Public smoke sample

This sample uses only Markdown and two geometric PNG diagrams created for Mono Space. No lesson screenshots, third-party photos, or external asset paths are used. The PNGs are 960 × 540 and contain colored rectangles only.

Run from the Space module directory:

```sh
python3 build.py examples/standard/document.md -o dist/examples/standard/presentation.html --offline
```

Check Japanese headings, paragraphs, local subheadings, lists, two/three-image galleries, a table, code indentation, and a quotation. Use the math sample separately for TeX rendering. Repository-wide distribution licensing remains to be selected.
